# Сайт: наклейки, этикетки, стикеры

Статический многостраничный сайт без сборки. Открывается прямо из папки, публикуется через GitHub Pages.

## Что поменять

- **Telegram-бот:** в `assets/main.js` впишите username бота в `SITE.bot` (без `@`). Все кнопки «Заказать» начнут вести на него.
- **Цена:** там же `pricePerCm2` и `minOrder` (калькулятор). Цифры в текстах страницы `ceny.html` правятся вручную.
- **Адрес и часы работы:** в `kontakty.html` (жёлтые заглушки).
- **Телефон:** поиск и замена `920-777-1` и `tel:9207771` во всех `.html`.

## Страницы

`index.html` главная · `uslugi.html` услуги · `ceny.html` цены и калькулятор · `kak-zakazat.html` как заказать · `kontakty.html` контакты · `404.html`
